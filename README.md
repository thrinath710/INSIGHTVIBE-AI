# ⚡ InsightVibe AI — Enterprise Intelligence Dashboard

An advanced multimodal AI analytics application built for processing enterprise data assets (PDF vectors and CSV matrices) simultaneously using blazing-fast LLM compute layers.

## 🚀 Live Deployment
👉 **[Access the Live Application Here](https://insightvibe-ai.streamlit.app)**

---

## 🛠️ Tech Stack & Architecture
* **Frontend/UI:** Streamlit (Custom Premium Dark/Neon Aesthetic)
* **LLM Engine:** Groq API Cloud Layer (`llama-3.3-70b-versatile` & `llama-3.1-8b-instant`)
* **Data Visualization:** Plotly Express & Altair
* **Parsing Engines:** PyPDF2 (PDF text vectors) & Pandas (CSV structured matrix processing)

## 🌟 Key Features
* **Automated One-Shot Analysis:** Instantly extracts high-level summaries, key quantitative metrics, organization entities, and action items upon file upload.
* **Interactive Data Visualization Engine:** Dynamically renders trend lines, distribution bars, and scatter matrices for uploaded CSV files.
* **Contextual Interrogation Network:** Features a persistent chat history layout with token streaming outputs for immediate UI feedback.
